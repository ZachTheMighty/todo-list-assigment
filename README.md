This project taught me that if there's anything more difficult than writing code that works, it's that writing organized code that works.

Obviously the program isn't perfect, and I'm sure if I really tried I could find more bugs, but as it is I think I'm satisfied with what I have created, and I think it satisfies the assigment's instructions.
